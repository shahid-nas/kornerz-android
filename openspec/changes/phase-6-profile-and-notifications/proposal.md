## Why

> **See also:** [`docs/architecture.md`](../../../docs/architecture.md) for the MVVM + Repository + UDF contract, `AsyncValue<T>`, `Channel<NavEvent>`, module boundaries, Hilt scopes, and the canonical library list that every artifact in this change conforms to.

Phases P0–P5 shipped a populated Home, Kornerz, Nooks, and Loops tab on the shared Firebase backend (`kornerz-72fba`), plus the full signup / login / session / force-update plumbing. The fifth tab in the bottom navigation bar (`Profile`) is still the P0 "Coming in Phase 6" empty-state placeholder, and the account-management flows every signed-in user needs (view own profile, edit basic info, read privacy policy, see notifications, delete account) have no Android surface yet. Phase 6 ports the entire Profile & Notifications vertical. iOS (`kornerz/Kornerz/HomeVC/ProfileVC/`, `kornerz/Kornerz/HomeVC/Notifications/`, `kornerz/Kornerz/Backend/Repositories/NotificationRepository.swift`, `kornerz/Kornerz/Backend/Repositories/UserProfileRepository.swift`) is the **source of truth** for every Firestore read, every field, every sort order, every pagination cursor, and every interaction — the Android port uses Compose primitives, MVVM + Repository + UDF, and the canonical library list, but reaches behavioral parity so the two builds look identical in screenshots and walkthroughs. Backend integration is real (`kornerz-72fba`), there are no mock servers, and the phase ships an APK that compiles, launches, and is presentable to PM/QA for the "edit profile, change a field, view notifications, open privacy policy" demo.

For `notification` messages, displays a system tray notification via `NotificationManagerCompat` with channel `kornerz_notifications` (channel importance `IMPORTANCE_HIGH`, lights, sound, vibration). Channel is created at app startup. Deep-link routing from a tapped notification is **deferred to P10** (per `phases.md` P10 line 314). On Android 13+, requests `POST_NOTIFICATIONS` runtime permission at first session open via Accompanist `requestPermissionLauncher` — this is the Android-13+ equivalent of iOS's implicit push permission.

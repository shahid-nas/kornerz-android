# Satoshi font family

The Satoshi font files in `res/font/` are bundled from the upstream
Satoshi font family by Indian Type Foundry and are used under the
SIL Open Font License 1.1. They are bundled here **only** as embedded
application resources for the Kornerz Android app.

## Do not extract to public assets

These `.otf` files must NOT be:

- Re-packaged as a downloadable font for use outside the Kornerz app
- Re-uploaded to any public CDN, asset store, or design-system portal
- Modified and redistributed as a derivative font family

The fonts are licensed for use *within* the Kornerz product. If a
team outside Kornerz needs Satoshi, they should obtain it directly
from https://www.fontshare.com/fonts/satoshi.

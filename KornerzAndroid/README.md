# KornerzAndroid

Greenfield Android client for Kornerz. Phase 0 ships an empty Compose
shell that compiles, launches into a branded splash, and renders a
5-tab bottom-nav with empty-state placeholders. P1+ fills in the tabs.

## Module structure

```
KornerzAndroid/
├── app/                          ApplicationModule (entry point)
├── core/
│   ├── model/                    Placeholder for domain types (P1+)
│   ├── network/                  Firebase init only in P0
│   ├── storage/                  Placeholder for DataStore (P2+)
│   └── ui/                       Design tokens, theme, shared composables
├── feature/
│   ├── splash/                   Branded splash screen
│   └── shell/                    5-tab navigation host
└── gradle/
    └── libs.versions.toml        Version catalog
```

## Build flavors

| Flavor | applicationId              | app name      |
|--------|----------------------------|---------------|
| `dev`  | `com.kornerz.app.dev`      | `Kornerz Dev` |
| `prod` | `com.kornerz.app`          | `Kornerz`     |

The `dev` flavor installs side-by-side with `prod` so QA can compare.

## Build commands

From `KornerzAndroid/`:

```bash
./gradlew :app:assembleDevDebug      # build dev APK
./gradlew :app:assembleProdDebug     # build prod APK
./gradlew :app:installDevDebug       # install on a connected device
./gradlew :app:lintDevDebug          # run lint
```

## First-time setup

The Gradle wrapper jar (`gradle/wrapper/gradle-wrapper.jar`) and the
`gradlew` script are binary artifacts generated by the Gradle wrapper
task. To bootstrap on a fresh clone:

```bash
cd KornerzAndroid
gradle wrapper --gradle-version 8.10.2
```

Requires a system Gradle 8.x install; once the wrapper jar is present
the repo can be built without further setup. CI installs Gradle via
`./gradlew` once the jar is committed.

## Firebase

`app/google-services.json` is committed at the project root (it
contains public OAuth client IDs, not secrets). The Android team
needs Editor access to `kornerz-72fba` to upload the production
config; the file committed here is the dev project.

## CI

`.github/workflows/android-pr.yml` runs on every PR that touches
`KornerzAndroid/**`. The job checks out, sets up JDK 17, caches the
Gradle dependency directory keyed on the wrapper properties hash,
runs `:app:assembleDevDebug`, and uploads the resulting APK as a
workflow artifact.
